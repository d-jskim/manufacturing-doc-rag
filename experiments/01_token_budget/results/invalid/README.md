# 무효 처리 결과

## 1. 최종 비교용 질문 사용

- **대상**: 2026-11-09 18:52, 2026-11-10 10:01 실행 결과 파일 4개
- **무효 사유**: 설정 조정에 최종 비교용 질문을 사용함.
    - N 산정에 평가 질문 세 파일(`development.json`, `additional.json`, `expansion_validation.json`)을 모두 사용함.
    - 설정 조정은 개발 질문(`development.json`)만 사용해야 하며, 나머지 질문은 최종 비교에만 사용해야 함.
    - 최종 비교에 쓸 질문의 근거 분포가 설정에 반영되어 결과가 낙관적으로 나올 수 있음.
- **무효 범위**: 질문 근거를 사용한 값에 한정함.
    - 무효: 근거 페이지·문서 수 분포, N, 문맥 토큰 한도
    - 유효: 페이지 추출 결과, 페이지 토큰 수, 임베딩 입력 한도 초과 페이지 수·비율. PDF만 사용하여 평가 질문과 무관함.
- **조치**: 개발 질문만으로 재실행하고, 이 결과는 비교용으로 보관함.

## 2. 결과 항목 이름 규칙 불일치

- **대상**: 2026-11-10 10:22, 10:23 실행 결과 파일 2개
- **무효 사유**: 결과 항목 이름이 값의 의미를 정확히 나타내지 않음.
    - `embedding_tokens`, `generation_tokens`는 임베딩·생성 결과로 오해될 수 있으나, 실제 값은 각 모델 입력 기준의 토큰 수임.
    - `embedding_over_limit.pages`는 페이지 번호로 오해될 수 있으나, 실제 값은 임베딩 입력 한도(512토큰)를 넘는 페이지 수임.
    - `extraction.pages`는 값이 나온 기준(추출 성공 페이지 수)이 드러나지 않음.
- **무효 범위**: 결과 항목 이름에 한정하며, 측정값은 모두 유효함.
    - 개발 질문(`development.json`)만 사용하여 1번의 무효 사유는 해당하지 않음.
    - 10:22와 10:23은 같은 조건의 중복 실행이며 값이 동일함.
- **조치**: 값이 나온 로직을 드러내는 이름 규칙(`…_input_token_count`, `extracted_page_count`, `over_limit_page_count` 등)으로 코드를 수정하고 재실행함.

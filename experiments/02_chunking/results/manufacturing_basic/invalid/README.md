# 무효 처리 결과

## 1. Qdrant 접속 주소로 인한 시간 측정 오류

- **대상**: 2026-11-10 19:09 실행 결과 파일 3개(c1·c2·c3)
- **무효 사유**: 모든 Qdrant 요청에 약 2초의 지연이 더해져 시간 기록이 실제와 다름.
    - Qdrant 포트를 `127.0.0.1`(IPv4)에만 열었는데, 코드는 `localhost`로 접속함.
    - Windows는 `localhost`를 IPv6(`::1`)로 먼저 접속하려 하고, 실패를 확정하기까지 약 2초를 기다린 뒤 IPv4로 접속함.
    - 질문당 검색 시간이 exact·ANN 모두 약 2.06초로 기록됨. 색인 생성 시간(14~18초)에도 요청마다 같은 지연이 포함됨.
- **무효 범위**: 시간 기록에 한정함.
    - 유효: Hit@k, Recall@k, 근거 문장 포함률, k, ANN 순위 비교, 임베딩 입력 토큰 수
- **확인**: 주소를 `127.0.0.1`로 바꾼 재실행(19:22)에서 질문당 검색 시간이 exact 0.018초, ANN 0.007초로 줄었고, 품질 지표는 모두 같았음.
- **조치**: `experiments/02_chunking/config.yaml`의 `qdrant_url`을 `http://127.0.0.1:6333`으로 수정함.

## 2. 원인 확인용 실행(색인 재사용)

- **대상**: 2026-11-10 19:22 실행 결과 파일 3개(c1·c2·c3)
- **보관 사유**: 1번의 원인을 확인하려고 주소만 바꿔 실행한 결과임. 기존 색인을 재사용해 임베딩을 하지 않았으므로, 임베딩 시간과 토큰이 기록되지 않음.
- **유효 범위**: 품질 지표와 검색 시간은 유효함.
- **조치**: 색인 재사용 기록을 지우고 색인을 새로 만들어 다시 실행함(19:26). 19:26 결과를 공식 결과로 사용함.

# 04 검색 방식 비교 실험

> **요약**: 세 검색 방식(r1 의미 검색, r2 하이브리드, r3 하이브리드+재순위)을 같은 조건에서 비교함. 본 실험에 앞서, r2에 쓸 키워드 검색(BM25)의 단어 분리 방식을 사전 실험으로 정함. 한국어에 맞을 것으로 예상한 형태소 분석(Kiwi)이 띄어쓰기보다 낮게 나왔고, 원인을 확인한 뒤 **띄어쓰기**를 선택함.

## 1. 사전 실험: 키워드 검색 단어 분리 방식

### 1.1 목적

BM25는 질문과 문서에 같은 단어가 있는지로 점수를 매김. 한국어는 조사가 붙어 같은 단어도 모양이 달라지므로(예: "검토자가", "검토자는"), 단어 분리 방식에 따라 검색 결과가 달라질 수 있음. r2에 사용할 방식을 데이터로 정하기 위해 두 방식을 비교함.

### 1.2 설계

| 방식 | 설명 |
| --- | --- |
| whitespace | 소문자로 바꾼 뒤 띄어쓰기로 나눔 |
| kiwi | 형태소 분석기 Kiwi(`kiwipiepy`)로 나눈 뒤 명사·동사·형용사·외국어·숫자 등 내용어만 남김. 모델명·코드(예: `CV-20`)는 한 단어로 유지함 |

- **고정 조건**: `manufacturing_basic`, 청킹 c1, 질문 `development.json` 30개(평가 대상 29개), BM25 단독 검색, 후보 20개, 문맥 토큰 한도 1,582토큰
- **지표**: Hit@k, Recall@k(문서 단위), 근거 문장 포함률, 평균 k, 색인 생성 시간. 정의는 청킹 실험(`experiments/02_chunking/README.md`)과 같음.
- **예측**: 조사를 떼어 내는 kiwi가 whitespace보다 높을 것임.

### 1.3 결과

| 방식 | Hit@k | Recall@k | 근거 문장 포함률 | 평균 k | 색인 생성 시간 |
| --- | --- | --- | --- | --- | --- |
| whitespace | **0.724** | **0.552** | **0.310** | 2.10 | 0.02초 |
| kiwi | 0.517 | 0.397 | 0.190 | 2.07 | 3.94초 |

- 결과 파일: `results/manufacturing_basic/keyword_tokenizer_20261111_0516.json`
- 참고: 같은 조건의 의미 검색(r1, 청킹 실험 c1)은 Hit@k 0.759임. whitespace BM25 단독도 이에 가까운 수준임.

### 1.4 분석: 예측과 반대로 나온 원인

질문 하나(M-DEV-09)의 단어 분리 결과를 비교함.

| 원래 단어 | whitespace | kiwi | 문제 |
| --- | --- | --- | --- |
| 미확인인 | `미확인인` | `확인` | 접두사 "미-"가 빠져 **뜻이 반대**가 됨 |
| 검토자가 | `검토자가` | `검토` | 접미사 "-자"가 빠져 "검토하는 사람"이 "검토"가 됨 |
| (문장 전체) | — | `대하`, `적`, `하`, `있` 추가 | 거의 모든 문서에 나오는 동사가 단어로 들어가 변별력 없는 일치가 늘어남 |

- kiwi 하락의 원인은 형태소 분석 자체보다, 남길 품사를 고른 설정에서 접두사·접미사를 제외한 데 있음.
- whitespace가 높은 이유는 평가 질문이 문서의 표현을 그대로 가져다 쓴 경우가 많기 때문임. 조사가 붙어 있어도 질문과 문서의 모양이 같으면 정확히 일치함.

### 1.5 결정과 한계

- **결정**: r2의 키워드 검색은 whitespace를 사용함. 점수가 높고 색인 생성도 약 200배 빠름.
- 하이브리드에서는 의미 검색이 조사·표현 차이를 보완하므로, 키워드 검색은 모델명·용어처럼 글자가 정확히 같은 경우를 잡는 역할에 집중함.
- **한계**
    - Kiwi의 품사 설정(접두사·접미사 포함 등)을 바꿔 다시 비교하지는 않음. 설정 조합이 많아 비교가 끝없이 늘어나므로 이 단계에서 멈춤.
    - 평가 질문이 문서 표현을 재사용하는 특성이 whitespace에 유리하게 작용했을 수 있음. 실제 사용자가 다른 표현으로 묻는 경우에는 결과가 달라질 수 있음.
